O **SearchAIO** reúne buscadores tradicionais e serviços de IA em um centro de busca diário e cria links compartilháveis que mostram o processo de pesquisa.

**[📖 Apresentação do projeto](https://www.cxthhhhh.com/search-aio/)** | **[➡️ Demo online](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**

![Captura do SearchAIO](https://github.com/MeowLove/SearchAIO/raw/main/img/SearchAIO_Screenshot_EN.png)

## ✨ Recursos

- Alterne rapidamente entre 76 serviços de busca web, especializados e de IA.
- Consulte a descrição de cada mecanismo para escolher a ferramenta adequada.
- Suporte a chinês, inglês, russo, espanhol, francês, árabe, português do Brasil, japonês e alemão.
- Temas claro/escuro, layout responsivo e favoritos locais; as preferências ficam no navegador.
- Crie links compartilháveis que demonstram o fluxo de pesquisa.

## 🚀 Como usar

### Central de busca pessoal

https://github.com/user-attachments/assets/41f9c122-5d37-46cb-99c3-886bb2dab3d0

1. Acesse a **[demo online](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**.
2. Escolha um mecanismo, digite a consulta e pressione `Enter` ou o botão de busca.
3. Use `google: consulta` ou `!g consulta` para encaminhar diretamente.

### Link de tutorial

1. Escolha o mecanismo e digite uma pergunta.
2. Clique em “Criar link de tutorial (copiar)”.
3. Envie o link para quem precisa aprender o fluxo de busca.

## 🛠️ Desenvolvimento e publicação

O projeto usa HTML, CSS, JavaScript puro e ES Modules, sem dependências de runtime. Depois de alterar `src/*.js`, execute `npm run build:static`; para publicar, renomeie `SearchAIO.html` para `index.html`. Após alterar o registro, abra `SearchAIO.html?selftest=1` ou execute `npm test`.
