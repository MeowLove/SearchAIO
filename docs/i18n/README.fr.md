**SearchAIO** réunit les moteurs de recherche traditionnels et les services d’IA dans un centre de recherche quotidien, avec des liens partageables pour montrer le parcours de recherche.

**[📖 Présentation du projet](https://www.cxthhhhh.com/search-aio/)** | **[➡️ Démo en ligne](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**

![Capture SearchAIO](https://github.com/MeowLove/SearchAIO/raw/main/img/SearchAIO_Screenshot_EN.png)

## ✨ Fonctionnalités

- Basculez rapidement entre 76 services web, spécialisés et IA.
- Consultez la description de chaque moteur avant de choisir l’outil adapté.
- Interface disponible en chinois, anglais, russe, espagnol, français, arabe, portugais brésilien, japonais et allemand.
- Thèmes clair/sombre, interface responsive et favoris locaux ; les préférences restent dans le navigateur.
- Créez des liens partageables qui montrent le déroulement d’une recherche.

## 🚀 Utilisation

### Centre de recherche personnel

https://github.com/user-attachments/assets/41f9c122-5d37-46cb-99c3-886bb2dab3d0

1. Ouvrez la **[démo en ligne](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**.
2. Choisissez un moteur, saisissez une requête et appuyez sur `Entrée` ou le bouton de recherche.
3. Utilisez `google: requête` ou `!g requête` pour diriger directement la recherche.

### Lien de tutoriel

1. Choisissez le moteur à présenter et saisissez une question.
2. Cliquez sur « Créer un lien de tutoriel (copier) ».
3. Envoyez le lien à la personne qui doit apprendre le parcours de recherche.

## 🛠️ Développement et déploiement

Le projet utilise HTML, CSS, JavaScript natif et ES Modules, sans dépendance d’exécution. Après une modification de `src/*.js`, lancez `npm run build:static` ; pour publier, renommez `SearchAIO.html` en `index.html`. Après une modification du registre, ouvrez `SearchAIO.html?selftest=1` ou lancez `npm test`.
