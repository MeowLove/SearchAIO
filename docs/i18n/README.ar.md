**SearchAIO** يجمع محركات البحث التقليدية وخدمات الذكاء الاصطناعي في مركز بحث يومي واحد، مع روابط قابلة للمشاركة لعرض خطوات البحث.

**[📖 مقدمة المشروع](https://www.cxthhhhh.com/search-aio/)** | **[➡️ التجربة المباشرة](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**

![لقطة شاشة SearchAIO](https://github.com/MeowLove/SearchAIO/raw/main/img/SearchAIO_Screenshot_EN.png)

## ✨ المزايا

- التبديل بسرعة بين 76 خدمة للبحث على الويب والبحث المتخصص والذكاء الاصطناعي.
- عرض وصف وظيفة كل محرك لاختيار الأداة المناسبة.
- دعم الصينية والإنجليزية والروسية والإسبانية والفرنسية والعربية والبرتغالية البرازيلية واليابانية والألمانية.
- مظهر فاتح/داكن وتصميم متجاوب ومفضلات محلية؛ تبقى التفضيلات داخل المتصفح.
- إنشاء روابط قابلة للمشاركة تعرض رحلة البحث خطوة بخطوة.

## 🚀 الاستخدام

### مركز البحث الشخصي

https://github.com/user-attachments/assets/41f9c122-5d37-46cb-99c3-886bb2dab3d0

1. افتح **[التجربة المباشرة](https://www.cxthhhhh.com/CXT-Lib/SearchAIO/)**.
2. اختر محركاً، اكتب الاستعلام، ثم اضغط `Enter` أو زر البحث.
3. استخدم `google: استعلام` أو `!g استعلام` للتوجيه المباشر.

### رابط الشرح

1. اختر المحرك واكتب السؤال.
2. اضغط «إنشاء رابط شرح (نسخ)».
3. أرسل الرابط إلى من يحتاج إلى تعلم طريقة البحث.

## 🛠️ التطوير والنشر

يستخدم المشروع HTML وCSS وJavaScript الأصلي وES Modules من دون اعتماديات تشغيلية. بعد تعديل `src/*.js` شغّل `npm run build:static`؛ وعند النشر أعد تسمية `SearchAIO.html` إلى `index.html`. بعد تعديل سجل المحركات افتح `SearchAIO.html?selftest=1` أو شغّل `npm test`.
